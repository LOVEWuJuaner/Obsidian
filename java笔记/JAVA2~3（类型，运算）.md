### 基本数据类型与引用数据类型
- 基本数据类型：四类八种，数据值存在自己的空间，赋值给别的变量，给的是真实值
- 引用数据类型：本身的空间存地址，值在其他空间，赋值给别的变量，给的是地址值
- 如数组，本体在堆内存中，arr是一个指向堆内存的地址
- （String（本质是char数组）也是引用数据类型）
- 一个new出来的对象也是引用数据类型，对象本身存的是一个指向堆的地址
- ![[Pasted image 20260724140232.png]]
- 基本数据类型传入函数，不会对本身产生改变
- 引用数据类型传入函数，因为传的是地址，函数内部可以通过地址修改本体，如arr[1] = 0

# 3.运算符
## 3.1隐式转换
大小顺序：byte short int long float double
### 两种提升规则：

- 取值范围小的，和取值范围大的进行运算，小的会先提升为大的，再进行运算。
    
- byte、short、char三种类型的数据在运算的时候，都会直接先提升为int，然后再进行运算。
## 3.2强制转换
### 概念：

如果要把一个取值范围大的数据或者变量赋值给另一个取值范围小的变量。是不允许直接操作。

如果一定要这么干，就需要加入强制转换。

### 书写格式：

目标数据类型 变量名 = （目标数据类型）被强转的数据；
## 3.3字符串+操作
- 当+操作中出现字符串时，此时就是字符串的连接符，会将前后的数据进行拼接，并产生一个新的字符串。（只要有一个字符串，最终结果就是一个字符串）
    
- 当连续进行+操作时，从左到右逐个执行的。
-案例：

1 + 2 + "abc" + 2 + 1

结果：“3abc21”
## 3.4字符+操作
### 规则：

当+操作中出现了字符，会拿着字符到计算机内置的ASCII码表中去查对应的数字，然后再进行计算。

### 案例：
```java
char c = 'a';  
int result = c + 0;  
System.out.println(result);//97
```
## 3.5赋值运算符
### 注意点：

扩展的赋值运算符中隐层还包含了一个强制转换。

以+=为例。

a += b ;实际上相当于 a = (byte)(a + b);
```java
public class OperatorDemo8 {  
    public static void main(String[] args) {  
        byte a = 10;  
        byte b = 20;  
        //a += b;  
        a = (byte)(a + b);  //a+b默认转为int，为了能赋值给左边，自动强转为左边的类型
        System.out.println(a);//30  
    }  
}
```

## 3.7三元运算符
### 格式：

关系表达式 ？ 表达式1 ：表达式2 ；
```java
String result = weight1 == weight2 ? "相同" : "不相同";
```
### 计算规则：

- 计算关系表达式的值。
    
- 如果关系表达式的值为真，那么执行表达式1。
    
- 如果关系表达式的值为假，那么执行表达式2。
    

### 注意点：

三元运算符的最终结果一定要被使用，要么赋值给一个变量，要么直接打印出来。
